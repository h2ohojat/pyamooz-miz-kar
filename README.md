# میز کار پای‌آموز

میزهای کار دورهٔ **«ساخت کاربرگ تعاملی و بازی‌وارسازی دروس»** پای‌آموز، برای ساختن کاربرگ تعاملی و بازی آموزشی فارسی با کمک دستیار هوش مصنوعی.

| پوشه | چه دارد |
|---|---|
| [karbarg](karbarg) | موتور کاربرگ، قالب آغاز و چهار نسخهٔ آمادهٔ کاربرگ کسر |
| [bazi](bazi) | سازندهٔ بازی، قالب آغاز «بازی من» و منبع کامل بازی «پل کسرها» |
| [SEFARESH.md](SEFARESH.md) | سفارش‌های آماده برای دستیار |

## راه اول: با یک لینک (پیشنهادی)

دستیاری لازم است که بتواند فایل بنویسد و فرمان اجرا کند، مثل دیپ‌سیک هارنس. یک پوشهٔ خالی را فضای کار دستیار قرار دهید و این سفارش را بفرستید:

```text
مخزن https://github.com/h2ohojat/pyamooz-miz-kar را در همین پوشه با git clone دریافت کن. اگر git در دسترس نیست، فایل https://github.com/h2ohojat/pyamooz-miz-kar/archive/refs/heads/main.zip را بگیر و از حالت فشرده بیرون بیاور.
بعد وارد پوشهٔ karbarg شو و از این به بعد فقط در همان پوشه کار کن. اول AGENTS.md و README.txt آن را بخوان.
نسخهٔ Node.js را با node --version گزارش کن و چیزی نصب نکن. بعد node build.cjs worksheet.html را اجرا کن.
فقط بگو ساخت موفق بود یا نه و فایل نهایی کجاست. اگر خطایی دیدی، متن دقیقش را بگو.
```

چت معمولی که فقط متن می‌نویسد و فرمان اجرا نمی‌کند، نمی‌تواند میز کار را راه بیندازد.

## راه دوم: بدون git

از دکمهٔ سبز **Code** گزینهٔ **Download ZIP** را بزنید، فایل را از حالت فشرده بیرون بیاورید و پوشهٔ `karbarg` یا `bazi` را فضای کار دستیار قرار دهید. سفارش‌های «آماده‌سازی» در [SEFARESH.md](SEFARESH.md) هستند.

## پیش‌نیاز

فقط [Node.js](https://nodejs.org) (نسخهٔ پیشنهادی). هیچ کتابخانه یا نصب دیگری لازم نیست. فایل نهایی کاربرگ و بازی فقط مرورگر می‌خواهد و بدون اینترنت باز می‌شود.

## قاعده‌ها

- فایل نهایی (HTML) را دستی ویرایش نکنید؛ هر تغییر از راه فایل محتوا و ساخت دوباره.
- پوشه‌های `engine` و `fonts` را تغییر ندهید.
- راهنمای دستیار در `AGENTS.md` هر پوشه است.
