# میز کار کاربرگ؛ دورهٔ ساخت کاربرگ تعاملی و بازی‌وارسازی دروس
پیش از هر ویرایش، README.txt و docs/PYAMOOZ_CONTENT_CONTRACT.md را بخوان.
فقط lesson.js و worksheet.css منبع قابل ویرایش‌اند. فایل HTML خروجی تولیدشده است؛ آن را دستی ویرایش نکن.
پوشهٔ engine کپی موتور موجود پای‌آموز است؛ آن را تغییر نده و موتور تازه نساز. وابستگی، نصب بسته، شبکه، CDN، iframe، eval یا ذخیره‌سازی موازی اضافه نکن.
برای هر فعالیت id انگلیسی کوتاه و ثابت بگذار. با تغییر محتوای منتشرشده version را بالا ببر؛ اگر ترتیب یا معنای سؤال‌ها عوض شد، محتوای تازه با id تازه بساز.
ساخت: node build.cjs worksheet.html (یا worksheet-نام.html). موفقیت را فقط پس از اجرای واقعی ساخت اعلام کن و متن دقیق خطا را گزارش کن.
وقتی معلم «طرح» خواست، هنوز فایل نساز. وقتی گزارش ایراد داد، فقط همان ایراد را اصلاح کن و بگو چه چیزی را آزمودی.
نقطه‌های آماده در checkpoints هستند؛ برای برگشت، محتوای یکی از آن‌ها جای lesson.js می‌نشیند.
پاسخ فارسی، کوتاه و بدون کد طولانی باشد. ادعای آزمون مرورگر یا اجرا در پای‌آموز فقط پس از انجام همان آزمون مجاز است.
